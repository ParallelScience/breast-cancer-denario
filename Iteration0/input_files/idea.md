Title: Optimizing Clinical Utility: Interpretable Logistic Regression for High-Sensitivity Breast Cancer Diagnosis using Core Nuclear Features.
Description: Develop an interpretable, cost-sensitive diagnostic classifier leveraging the most discriminative `worst` nuclear morphology features from the WDBC dataset. A regularized logistic regression model, optimized with `class_weight` to prioritize malignant recall, will establish a robust decision boundary, aligning with the dataset's near-linear separability. Model calibration via `isotonic regression` will ensure reliable probability estimates crucial for clinical risk assessment. Nested cross-validation will provide robust performance metrics, focusing on sensitivity at high specificity and confidence intervals. SHAP values will then transparently quantify the contributions of original morphological measurements, providing an actionable, clinically interpretable signature for improved breast cancer diagnosis.
